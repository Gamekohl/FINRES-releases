# FINRES

A desktop companion for Microsoft Flight Simulator. FINRES turns real
airline timetables into rotations: pick a carrier, chain legs off its
departure board, dispatch every sector in SimBrief — the app watches
your simulator and logs each sector as you fly it.

Windows 10/11, 64-bit.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

| File | What it is |
| --- | --- |
| `FINRES.exe` | Portable single file — put it anywhere and run it |
| `FINRES-Setup-*.exe` | Classic installer, if you'd rather have one |

Both builds update themselves automatically when a new version ships.

## What it does

- Browse real airline route networks and schedules
- Chain legs into rotations and send each one to SimBrief
- Live map with your aircraft, ATC areas, North Atlantic tracks,
  rain and wind overlays
- Watches the simulator, interpolates your position and writes a
  logbook as you fly
- Hangar for your add-ons, friends, shared flights

## Notes

- Windows SmartScreen may warn on first start — the binaries are not
  code-signed. *More info → Run anyway* gets you through.
- FINRES is a fan project and is not affiliated with any airline.
- The source code is private; this repository only hosts releases.
  Found a bug? Please open an issue here.
